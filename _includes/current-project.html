What I'm building now (current project)

Kinesis

Kinesis is a desktop app for keeping and studying the videos you learn from. It saves YouTube videos along with their transcripts, so you can search, summarize, tag and file them, and link them to each other. You can also plan videos into a schedule, like a course or a workout program, and create flashcards to improve studying.

I started Kinesis to solve a gap between visual learning through online videos and organization. The design document goes into how it all works.
